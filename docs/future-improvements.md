## Future improvements

### Stronger visual identity
Replace the current neutral palette with a more colours or the capybara mascot in the App icon. 

### Easier category deletion
Allow users to move all affected transactions and templates to another category before deleting the old category.

### Backup and restore
Let users export and import their data. A later version could encrypt the backup with a password using the Web Crypto API and AES-GCM.

### Clearer sync status
Show whether the app is offline, syncing, or fully up to date. Also test what happens when the same record is edited on two devices.

### Stronger privacy
Research end-to-end encryption so cloud data can only be read by the user. Clearly document what stays on the device and what is sent to the sync service.
