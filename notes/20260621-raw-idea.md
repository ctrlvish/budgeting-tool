### raw idea

Create a budgeting tool using vite and dexie.js (indexeddb wrapper) so data fully local. this is to track my 50 30 20 spendings and deploy to web so anybody can use. 

You can download 'backups' of your data and import back simply, no need for auth or backend so its fully offline.

I can release the source code to download and run locally, and deployed online. 

A small add-on for the 'offline' feel is using vite-plugin-pwa which is a vite service worker to cache all the data so after page visit if connection is lost, the app can still be used.

I want to analyse my current workflow with excel and just try to refine my current approach for quicker expense entries and better visual dashboards.

drawbacks i can think of now:
1. cannot be used on multi devices since data is stored locally and moving backup files to multiple devices makes it confusing.
2. browser storage isnt indestructable, i am relying on user doing manual backups as the only safety net, and it quickly gets outdated. 
3. makes more sense as an app than on browser, this is not a severe issue tho.
